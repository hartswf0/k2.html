# Sketchsong Band

Microscope rejoined with the rest of the ensemble.

Two scales:
- BAND: prompt → variety → theory → arrangement → listener
- MICRO: tap any player to inspect and evolve its sound inside the arrangement

Same permanent grammar at both scales:
PLAY · ASK · MORE · +

Band features:
- 4–8 agent-composed players
- 16-step editable patterns
- explicit variety and theory rail
- whole-band listener tension
- per-track microscope
- four orthogonal child players: BODY, RHYTHM, TIMING, STRANGER
- long-press a child to USE IN BAND
- per-object chat
- mobile-first, no page scroll
