# Sketchsong / Orchestrator Test

A separate experimental branch of WORD / SKETCH / SONG.

The operative model is:

`source panel → panel agent → translation theory → playable code → song → listener/spectrum → branch`

## What is different

- Every major panel has its own contextual chat agent.
- The top rail exposes SOURCE → THEORY → CODE → LISTEN as visible orchestration stages.
- CODE is canonical and playable: edit the small Sketchsong score language and press RUN.
- Clicking a note in SONG locates its generating NOTE line in CODE.
- Theory rules are editable hypotheses and can be kept as stepping stones.
- Desktop column widths and each column's vertical split are draggable.
- Any panel can take the whole workspace with its focus control.
- Mobile is fixed-height and horizontally snaps FROM / THROUGH / TO.
- FLOW records transformations, chats, patches, code runs, and branches.
- Chat accepts dragged/pasted images.
- Exports: song JSON, playable score code, trace JSON, standalone HTML, WAV.

The existing `word-sketch-song/` instrument remains unchanged.
