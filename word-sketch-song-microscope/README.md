# Sketchsong Microscope

The information architecture is deliberately reduced to three things:

- current sound or relationship
- four children
- lineage / sediment

Permanent actions: `PLAY · ASK · MORE · +`

Key behaviors:

- drop audio anywhere
- drag across the combined waveform/spectrum body to mark a region
- `MORE` produces exactly four orthogonal children: `BODY`, `RHYTHM`, `TIMING`, `STRANGER`
- tap a child to hear it and enter it
- long press a child to `KEEP` it and add it to the relationship selection
- when 2+ sounds are selected, `MORE` generates four relationship children: `SPACE`, `LATE`, `BROKEN`, `CROSS`
- `ASK` attaches to the current object and can return an audible mutation
- `CAUSE` shows the executable transformation recipe
- `LINEAGE` reveals sediment only on demand
- fixed mobile viewport; no vertical page scroll
