# Sketchsong Sound Ecology

Mobile-first recursive sound-foraging branch.

- Drop one or many audio files anywhere.
- Every sound becomes a creature with measured features, parents, descendants, spectrum, recipe and trace.
- FORAGE/BREED makes six AI mutation descendants; without API it falls back to local Monte Carlo mutations.
- SCULPT lets a waveform mark become an excavated child.
- Draw directly on the spectrogram and send it to the sound's chat/listener.
- ASK talks to the current sound; the agent can answer by returning an executable mutation recipe.
- GROOVE creates a 1–4-creature circle, asks Groove Hound for four contrasting 16-step relationships, and renders any candidate into a new creature.
- Listener passes inspect rendered features + spectrogram and leave a reusable fragment mark.
- Sediment preserves ancestry rather than overwriting runs.
- Export WAV or provenance JSON.
- No vertical page scroll.
