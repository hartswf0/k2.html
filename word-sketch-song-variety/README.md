# Sketchsong Variety

Static GitHub Pages branch of Sketchsong.

The upstream Variety Agent chooses one stepping stone across eight dimensions before Theory and Code: lineage, place, rhythm, form, instrument, production, tuning, aberration.

Built in:
- 128 General MIDI program names
- 47 General MIDI percussion notes
- 16 channels
- variable meter, form, section count, and ensemble size
- GM / SYNTH / PERC / NOISE track types
- editable executable Sketchsong code
- MIDI / JSON trace / code / standalone HTML export
- per-panel contextual agents
- resizable and focusable operative panels
- novelty-distance control and lockable stepping stones

Use VARIETY → IMPORT to load `treblo_tags_v3.txt`. The complete imported reservoir is stored in localStorage for later sessions.
